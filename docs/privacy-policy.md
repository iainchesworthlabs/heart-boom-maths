# Privacy policy

> **Draft for the owner's review.** Not yet published as the final policy. Items marked "owner to supply" or "to confirm" must be settled before it is linked from a store or from the app. The checklist of claims to verify is in [Release checklist](release-checklist.md).

Heart Boom Maths is a mental-arithmetic game for children from 5 to 12. It is made by Iain Chesworth Labs.

Effective date: owner to set at release.

## The short version

- The game collects no personal information.
- It has no accounts, no ads, no purchases, no chat, no analytics and no crash reporting.
- It does not use your location, camera, microphone, contacts or photos, and it does not send notifications.
- Everything the game remembers stays in a small file on your own device.
- The game makes no network requests of its own.

## What the game saves on your device

The game keeps one small save file on the device, so a child can pick up where they left off. It holds:

- the coins earned;
- the sound and music settings, and the Game Center setting on Apple devices;
- the top 10 scores, each with the name the child typed (up to 12 letters);
- one interrupted game, so that CONTINUE can resume it once.

The game never uploads or shares this file. The device's own backup (for example iCloud or Android backup) may include it, under the device's settings. The game never sends a name typed into the top 10 anywhere. We suggest a nickname rather than a real name.

To remove the saved data, delete the app, or clear the app's storage in the device settings. In the web version, clear the site's data in the browser.

## Links out of the game

The About screen has links to this policy and to the game's source code. A link opens only after a grown-up passes a parental gate: the game shows a number in words, and the adult types it back as digits. The link then opens in the device's web browser, and from that moment the website's own privacy policy applies.

No other part of the game can open a web address.

## Game Center (Apple devices only)

On iPhone and iPad the game can send a finished score to Apple's Game Center leaderboard. This is off by default. A grown-up must pass the parental gate to switch it on in Settings. While it is off, the game never contacts Game Center.

When it is on, the game sends one number, the final score. It does not read the player's Game Center name, picture or friends, and it does not send the names typed into the game's own top 10. What Game Center does with the score, and what it shows to other players, is set by Apple and the device's parental controls. See Apple's Game Center privacy information.

Game Center does not exist on Android, Windows, Linux or macOS builds of the game, and the game has no equivalent there.

## The web version

The web version runs in the browser. The game's files are downloaded from the web host the owner chooses (to confirm), which may keep ordinary server logs such as the IP address of each visit, as any website does. The game itself sends nothing after it has loaded. Its save file is kept in the browser's own storage on your device.

## The app stores and the device

When you download the game, the app store (Apple, Google) handles the download under its own privacy policy. Parental controls such as Screen Time, Downtime, Family Link and Digital Wellbeing belong to the device. The game does not read or change them. If a limit takes the game out of the foreground, the game pauses and saves, and nothing else.

## Children

The game is designed for children from 5 to 12. Because it collects no personal information from anyone, there is nothing to ask a parent to consent to or to delete under rules such as COPPA in the United States or the GDPR in Europe. If this ever changes, this policy will change first, and the change will be described in the release notes.
