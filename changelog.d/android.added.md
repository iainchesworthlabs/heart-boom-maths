**Android.** The game builds for Android phones and tablets (`arm64-v8a`, Android 9 and later) as an APK and an AAB, with the `android-arm64-release` and `android-arm64-debug` presets. The package asks for no permission at all, keeps its save out of Google's cloud backup, and is locked to portrait on phones. The launcher icon is a placeholder. A separate, optional check (`android-build.yml`) builds both presets and fails if a package asks for any permission or a release is debuggable.
