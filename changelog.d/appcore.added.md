**The app layer is built, without screens.** `GameController` drives the game session from a clock, turns real time into whole ticks (with a catch-up limit after a stall), pauses and saves when the app leaves the foreground, plays the sounds of the feedback table through an audio service, submits the final score once, saves the wallet, settings, top 10 and the paused run, and restores that run on CONTINUE. A parental gate (a number in words, typed back) guards every link and the Game Center switch. The save is a file written atomically, a damaged file is kept as `save.json.bad`, and a newer file is never overwritten. The build number, commit and Qt version are generated at configure time, and one notices text gathers the Qt, dependency and font licences for About.
