**The release workflow builds the game for TestFlight.** The iOS job now compiles, signs and checks the whole game (not the one-screen stub) and has Apple validate it, and a tag or a manual run with `upload_testflight` sends it to TestFlight. The Game Center entitlement is requested only when the provisioning profile carries it (`HEART_BOOM_MATHS_IOS_GAME_CENTER`), so a build can be signed before the capability is turned on, and the check of the bundle accepts both states.
