**Whole games can be replayed, played in a terminal and checked by hash.** The core can read a replay file (a seed and commands with their ticks), run it through the game session and compare the events hash, the final state hash and the score. A text harness plays a complete 12-level game or endless play from a seed, a script or a built-in policy and records replays, five golden replays are stored, and property tests run the real question generator end to end at every level.
