**The game runs in a browser.** The `wasm-release` preset builds a static site: a page with a loading message and a policy that lets it reach nothing but its own files, and the game as one WebAssembly module. The save is kept in the page's storage and survives a reload, a hidden tab pauses and saves the run, and a browser that blocks storage gets a game that plays and keeps its save for the session only. A workflow checks the site, its size and a start in Chrome, and replays the golden games under Node so the rules are shown to play the same on WebAssembly as on Linux.
